03 — Analysis Pipeline (POST /analyze → POST /generate)
STAGE 1
EXTRACT
LLM
Claude parses raw CV (PDF/DOCX/TXT) + JD into structured JSON schema.

Outputs: nama, skills, pengalaman, angka_di_cv, entitas_klaim, jd requirements.
extract_v5_<hash> · 24h
STAGE 2
ANALYZE
Pure JS
Deterministic skill match scoring, format issue detection, archetype classification, red-flag detection.
part of analysis_v15_* · 48h
STAGE 2.5
ROLE INFER
Pure JS
Keyword-based role / seniority / industry classifier. Feeds weight bias into scoring, diagnose context, and tailor mode.
part of analysis_v15_* · 48h
STAGE 3
SCORE
Pure JS
5D weighted formula → skor [0–100], verdict (DO / TIMED / DO NOT), skor_sesudah, timebox_weeks. Role-weight bias applied.
part of analysis_v15_* · 48h
STAGE 4
DIAGNOSE
LLM
Claude generates human-readable gap explanations, recommendations, strengths. Cannot alter scores — read-only.
part of analysis_v15_* · 48h
STAGE 5
REWRITE
LLM
Claude tailors CV bullets to match JD keywords. Ground-truth block (angka_di_cv, entitas_klaim) prevents hallucination. rewriteGuard validates every bullet.
gen_id_v4_* / gen_en_v4_* · 48h
STAGE 6 · VALIDATE — After every LLM call (1, 4, 5). JSON schema check + 1 automatic retry on failure.
MODELS — Prod extract/diagnose: claude-sonnet-4-6. Staging + all tailoring: claude-haiku-4-5-20251001
04 — Scoring Model
north_star
CV content ↔ JD title token match. Primary relevance signal.
recruiter_signal
Formatting, typos, professional tone. ATS scannability.
effort
Gap size → improvement potential via tailoring.
risk
Red flags, experience gaps, archetype fit.
portfolio
Numbers/metrics in CV. Track record evidence.
verdict DO ≥70 + effort≥6 ▶ TIMED 50–69 ▶ DO NOT <50 red-flag penalty -15 (1) · -20 (2) · -25 (3+) · extra -10 on ATS/format flags skor_sesudah = skor + 10 + improvement, rounded ×5, clamped [skor+10, 95]
05 — Session State Machine
pending_payment
Invoice created. Awaiting Mayar webhook payment confirmation.
paid
Payment confirmed. No generation started yet. Credits full.
generating
CV tailoring in progress. Lock held 120s. Blocks duplicate requests.
ready
Generation succeeded. Credits remaining. Can regenerate.
exhausted
All credits consumed. Session preserved (not deleted). Terminal.
FROM TO TRIGGER ACTION
pending_payment → paid POST /webhook/mayar (payment confirmed) Update session, send confirmation email
paid → generating POST /get-session (first generation) Acquire lock_<id>, transition
ready → generating POST /get-session (multi-credit reuse) Acquire lock, transition
generating → paid POST /generate FAILED Rollback — no cv_result_ written
generating → ready POST /generate SUCCEEDED, credits > 0 Store cv_result_, release lock
generating → exhausted POST /generate SUCCEEDED, last credit Store cv_result_, release lock, send email
Legacy: old sessions may carry pending (PENDING_LEGACY) instead of pending_payment — mayarWebhook.js accepts both.  ·  Lock TTL: 120s (KV)  ·  Invoice lock: 60s  ·  Idempotency sentinel: 48h

✓

✓

✓

✓
Rate limiting: Cloudflare native + KV fallback — both must allow a request.
✓

✓

✓
Webhook idempotency sentinel written BEFORE session update — protects against Mayar retries.

14 — Security Model
SESSION + AUTH
🔒
HttpOnly session cookie — session_id in cookie, session_secret in header. Constant-time comparison prevents timing attacks.
🔒
IP-bound CV upload — cvtext_<token> is bound to the uploading IP. Cross-IP access rejected with mismatch error.
🔒
Email tokens — 128-bit hex, 1h TTL, single-use. Deleted on first exchange. Prevents session hijacking via forwarded emails.
🔒
CORS by origin header — Session-mutating endpoints verify origin against allowlist before issuing CORS headers. Allowed: gaslamar.com, www.gaslamar.com, gaslamar.pages.dev
INPUT + PAYMENT
🔒
File validation — Magic bytes checked server-side: PDF (%PDF), DOCX (PK). 5MB max. Never trust client MIME type.
🔒
Input sanitization — XSS prevention, control-char removal, Latin-1 encoding via sanitize.js.
🔒
Mayar webhook HMAC-SHA256 — Signature verified before any session mutation. Idempotency sentinel written BEFORE session update.
🔒
JD URL allowlist — fetchJobUrl.js suffix-checks domain against allowlist (LinkedIn, Indeed, Glassdoor…). URL shorteners intentionally blocked.

17 — Developer Gotchas
Stale cache
Changed a prompt or scoring formula? Bump the version in cacheVersions.js. Old key = old result. Most common silent bug.
IP mismatch
cv_text_key is bound to the uploading IP. Testing across IPs or proxies will reject with mismatch error.
Frontend not updating
js/dist/ and js/vendor/ are gitignored. Run npm run build before testing — CI builds them fresh.
Double-gen race
Session lock lock_<id> TTL 120s. Retrying within that window silently blocks — looks like a hang.
Wrong env deployed
wrangler deploy without --env production goes to sandbox. Always use npm run deploy:prod.
Auth flash
hasil-guard.js must stay as synchronous inline <script>. If deferred or bundled, unauthenticated content flashes before redirect.
Silent email skip
RESEND_API_KEY is optional. If absent, all email sending silently no-ops — no error thrown. Easy to miss in staging.
Scoring snapshot is server-side
analyzing-page.js no longer writes to sessionStorage. scoring.js fetches from GET /get-scoring. Missing data? Check the cvtext_ KV entry.
CV silently truncated
tailoring.js truncates CVs at 4000 chars. Oldest experience entries are dropped without error or warning.
Coupon GET with body
Fetch API spec forbids GET bodies (throws TypeError). Mayar coupon validate must use query string params — not body. method:'GET' + body: silently returns valid:false.
CV export is client-side
DOCX/PDF files are generated entirely in the browser (docx.js + jsPDF from cvDataCache). The worker never serves file bytes.
konfidensitas discarded
diagnose.js returns a konfidensitas field but the orchestrator (analysis.js) ignores it. Stage 2 pure JS is always authoritative for confidence level.
